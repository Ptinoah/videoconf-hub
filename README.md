# Projet VideoConf Hub

Dans le cadre du cours de travaux pratiques de développement frontend avancé, vous devez concevoir et développer une application web complète en React. Cette application a pour vocation de centraliser et d'explorer les chaînes YouTube dédiées aux conférences techniques en développement logiciel et en cybersécurité, à l'image de Devoxx France, DEFCONConference, ou encore GDG France.

L'application, que vous nommerez VideoConf Hub, communiquera avec l'API YouTube Data v3 pour récupérer dynamiquement les chaînes, les playlists et les vidéos. Elle intégrera progressivement des fonctionnalités d'authentification et de persistance des données via Firebase.

Ce projet vous permettra de mobiliser et de consolider les compétences suivantes :
- Conception et développement d'une application React avec Hooks et gestion d'état
- Consommation d'une API REST tierce (YouTube Data API v3)
- Mise en place d'un workflow de développement professionnel (Git et GitHub Flow)
- Intégration de services cloud (Firebase Authentication et Firestore)
- Pratique du développement agile avec livraisons itératives
